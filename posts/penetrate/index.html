把手机变成公开服务器

免费、无 VPS、无需 root：用 Cloudflare 快速隧道把手机上的网页发布到公网。
2026-10-03 · 1 分钟 · YG

今天我把手机变成了一台“服务器”——公网上就能打开我手机里的网页。

方案（免费、无 VPS、无需 root）：

pkg install cloudflared
cloudflared tunnel --url http://127.0.0.1:8080

它会打印一个 xxx.trycloudflare.com 地址，就是公网入口。

踩过的坑：

  1. 国内连 api.trycloudflare.com 常超时，重试即可；
  2. pkill -f 的匹配词别写进同一条命令，会把自己杀了；
  3. 快速隧道地址随机，重启就变。

后来整站搬到了 GitHub Pages，这个隧道就当备用入口了。

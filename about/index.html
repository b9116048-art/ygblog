这博客在一台 OPPO 手机上用 Termux 写，Hugo 静态生成，推到 GitHub Pages 发布。 不花一分钱，也不需要服务器。

技术栈#

环节用什么
写作Markdown，在手机上用 MT 管理器 / nano 编辑
生成Hugo + PaperMod 主题（MIT）
发布纯 Python 走 GitHub Git Data API（api.github.com）
托管GitHub Pages（main 分支根目录）

为什么不用 git push？因为国内 github.com 时通时断，而 api.github.com 一直很稳。 发布脚本只用 API：blobs → trees → commits → PATCH ref。

怎么加文章#

blog-new "标题" "一句话摘要" [标签,标签]   # 生成 Markdown 并自动发布
blog-deploy                   # 重新生成 + 发布，约 1 分钟后线上生效

怎么加文件#

blog-addfile <文件或文件夹>    # 复制进分享目录，刷新列表页并直接发布
blog-delfile <文件名>          # 删除并发布

本地预览#

blog-preview        # 起 http://127.0.0.1:8099/ 看构建后的真实效果
blog-preview stop   # 结束

语言学习模块#

导航栏「语言学习」里是查词工具，一处输入、多个来源：

  • 释义、音标、真人发音 —— Free Dictionary API，免费开放，来自 Wiktionary
  • 近义词 / 联想词 / 押韵词 —— Datamuse，用来扩充表达
  • 权威释义与例句 —— 一键跳转 柯林斯词典（英英 / 英汉都有）
  • 中文对照 —— 剑桥、必应词典、有道，随手对照

搜词框有联想补全，查到之后点「☆ 收藏」会存进页面的字词卡片。 收藏夹放在你浏览器的 localStorage 里，不上传、本站也看不到，换台手机不会跟过去。

注意：顶部导航里的「搜索」是站内文章搜索（Hugo + Fuse.js）， 「语言学习」页里的搜词框才是查外部词典，两者不是一回事。

自用笔记#

整个站点的搭建笔记（目录结构、环境坑、工具链）记在手机上的 ~/BLOG-NOTES.md。

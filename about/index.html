这博客在一台 OPPO 手机上用 Termux 写，Hugo 静态生成，推到 GitHub Pages 发布。 不花一分钱，也不需要服务器。

技术栈#

环节用什么
写作Markdown，在手机上用 MT 管理器 / nano 编辑
生成Hugo + PaperMod 主题（MIT）
发布纯 Python 走 GitHub Git Data API（api.github.com）
托管GitHub Pages（main 分支根目录）

为什么不用 git push？因为国内 github.com 时通时断，而 api.github.com 一直很稳。 发布脚本只用 API：blobs → trees → commits → PATCH ref。

怎么加文章#

blog-new "标题" "一句话摘要"   # 生成 Markdown 并自动挂到首页
blog-deploy                   # 重新生成 + 发布，约 1 分钟后线上生效

怎么加文件#

blog-addfile <文件或文件夹>    # 复制进分享目录，刷新列表页并直接发布
blog-delfile <文件名>          # 删除并发布

语言学习模块#

侧边栏「语言学习」里有查词工具：输入英文单词，同时给出

  • 释义、音标、真人发音（Free Dictionary API，免费开放）
  • 一键跳转 柯林斯词典 看权威释义与例句
  • Datamuse 的近义词 / 押韵词 / 联想词，用来扩充表达

页脚的字词卡片保存在浏览器本地（localStorage），不上传任何地方，换手机不带走。
